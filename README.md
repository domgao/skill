# API Contract Workflow

A reusable agent skill for designing, reviewing, and implementing APIs across frontend and backend code. It covers endpoint paths and HTTP methods, request/response models, field naming, server-side comments, errors, streaming contracts, and client synchronization.

## Install in Codex

Use the Codex skill installer with this folder URL:

`https://github.com/domgao/skill/tree/main/.agents/skills/api-contract-workflow`

Or copy `.agents/skills/api-contract-workflow` into a skill directory that your agent discovers.

## Contents

- `SKILL.md`: workflow and API contract conventions
- `agents/openai.yaml`: Codex display metadata and default prompt
